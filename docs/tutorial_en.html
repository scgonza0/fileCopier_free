FileCopier Quick Start Guide

FileCopier lets you copy files selectively with fine-grained filters, then apply the result to a destination folder, one or more targets at once, or export a report.

**1. Choose a source folder**

Click *Source → Browse…*, pick the root folder to scan, then click **Load tree**. FileCopier reads the folder structure (no files are copied yet).

Main window after loading a source tree

**2. Filter what to copy**

Click **Filter** to open the filter dialog. Build rules (by name, extension, size, date, path). Free edition allows up to 2 rules; Pro removes the limit. Click **Apply** — matching files are listed in the *Preview*.

Filter dialog — build AND rules to narrow the selection

**3. Preview and confirm**

The Preview dialog shows every matched file. Uncheck anything you want to skip, then **Apply to main tree**. If a destination already contains a file with the same name, the *Conflicts* dialog tells you whether to overwrite, skip, or auto-rename.

Conflict dialog — resolve existing files at the destination

**4. Pick destination(s) and copy**

Enter a destination (or several), choose collision handling, then **Copy**. A progress dialog reports speed and a summary shows how many files/folders were copied, skipped, or conflicted.
